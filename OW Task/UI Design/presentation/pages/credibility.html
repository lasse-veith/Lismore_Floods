Credibility Model: Technical Detail

A Bühlmann credibility blend combines the geospatial evidence signal with the static estimate: Z(i) = n(i) / (n(i) + k), with k = 250. Few nearby observations → mostly static. Many similar, recent, nearby completions → mostly the real signal.

Each of the 9 cost components is estimated independently this way, then combined, so a property similar to nearby evidence on flooring but not on kitchen spec gets a properly mixed estimate, not one blended weight applied to everything.

Weighting & outlier protection

Distance decay is a gentle exponential tilt over a 15km range (not a hard cutoff), recency decays with a 30-day half-life, and a robust-MAD outlier dampener smoothly down-weights any completed job whose realized/static cost ratio sits beyond |z| = 3.0 from the local median, so a single unusually expensive (or cheap) nearby repair can't dominate the blend.
