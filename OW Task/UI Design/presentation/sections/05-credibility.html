05 Credibility Model

Updating the estimate as real repairs land

How it works
Plain language first — the maths is one click away

As each simulated repair completes, it becomes a real observation nearby properties can borrow strength from. Distance, recency, and similarity — same construction type, suburb, flooring or kitchen spec — determine how much weight one completed job lends to an unresolved neighbour's estimate.

A Bühlmann credibility blend then combines that geospatial signal with the static estimate: Z(i) = n(i) / (n(i) + k), with k = 250. Few nearby observations → mostly static. Many similar, recent, nearby completions → mostly the real signal.

Show the maths — Bühlmann formula & similarity variables

Weighting: distance decay over a 15km gentle range, recency half-life 30 days, and a robust-MAD outlier dampener beyond |z| = 3.0 — smoothly down-weighted, never a hard cutoff.

Blend: each of the 9 cost components is estimated independently, then allocated back using each component's static labour/material baseline share, before combining with Z(i) = n(i) / (n(i) + 250).
